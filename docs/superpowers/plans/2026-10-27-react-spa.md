# React SPA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Bootstrap page with a compact, mobile-friendly React SPA in the
saber-tooth look, served by Flask on port 8002, with a per-project track viewer.

**Architecture:** `web/` holds a Vite + React 19 + TypeScript app with plain CSS. A Node
stage in `app/Dockerfile` builds it; Flask serves `index.html` for `/` and `/p/<name>` and the
hashed files under `/assets/`. Three JSON endpoints feed it; event reading moves into a shared
`app/events.py` used by Flask and the MCP tools.

**Tech Stack:** React 19.3.1, react-router 7.18.4, Vite 8.3.5, TypeScript 6.0.3, vitest 5.0.5,
Testing Library, eslint 10 with typescript-eslint, prettier; Flask 3.1; Node 22 in the build stage.

**Spec:** [docs/superpowers/specs/2026-10-27-react-spa-design.md](../specs/2026-10-27-react-spa-design.md)

## Global Constraints

1. Dark only. Tokens copied from saber-tooth: stage `#110e1f`, panel `#1a1630`, panel-2
   `#231e40`, line `#2c2650`, red `#e0303a`, blue `#2e9be6`, ink `#ece9f7`, muted `#a39fbf`,
   amber `#e8a33d`, green `#3dd68c`, radius 8px, font stack
   `Bahnschrift, "DIN Alternate", "DIN 2014", system-ui, sans-serif`.
2. Content column max 720px; mobile breakpoint `max-width: 719px`; touch targets at least 44px.
3. CSP: `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:;
connect-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none';
form-action 'self'`. No CDN, no inline `<script>`, no `style=""` in HTML.
4. Web service published on `${BIND:-127.0.0.1}:${PORT:-8002}`; `task run` stays on 5000;
   Vite dev server on 5173.
5. `POST /upload` and `POST /download_yt` keep returning the ZIP unless the request's `Accept`
   prefers `application/json`.
6. Flask never imports `mcp`. Every name reaching the file system passes `storage.is_valid_name`.
7. Python: target py314, line length 100, `encoding="utf-8"` on text I/O, files under 300 lines,
   a lint waiver carries an inline reason. TypeScript: eslint `--max-warnings 0`, prettier with
   `.crepidoma/configs/.prettierrc`.
8. Package versions are exact pins (no `^`), the same as saber-tooth's react worktree.
9. Commit with `task dev:commit COAUTHOR="Claude Opus 5.5 <noreply@anthropic.com>" -- "<msg>" <paths>`.
   Never push. Every new module or test file gets its row in the folder README (the docs hook
   refuses otherwise).
10. Taskfile shell is POSIX sh (mvdan). Gate mid-lane with `task gate T="..."`; `task validate`
    once at the end.

```python
"""Reading what an analysis wrote: track CSVs, labels.json, meta.json.

Shared by the web app (app.py) and the MCP tools (mcp_tools.py), so it imports neither Flask
nor mcp. Readers, not validators: a malformed row is skipped, a missing or broken file reads
as empty. Callers check names with storage.is_valid_name before building a path.
"""

import csv
import json
from collections.abc import Iterator
from pathlib import Path
from typing import Any

import storage

# analysis.LABELS_NAME. Not imported: analysis loads onnxruntime and the note model.
LABELS_NAME = "labels.json"
# Lane order in the viewer and in project_events: drums, beats, then the pitched tracks.
TRACK_ORDER = ("kick", "snare", "hh", "beats", "bass", "chords", "melody")


def tracks(folder: Path) -> dict[str, Path]:
    if not folder.is_dir():
        return {}
    found = {path.stem: path for path in folder.glob("*.csv")}
    ordered = [stem for stem in TRACK_ORDER if stem in found]
    ordered += sorted(stem for stem in found if stem not in TRACK_ORDER)
    return {stem: found[stem] for stem in ordered}


def rows(path: Path) -> Iterator[tuple[float, int]]:
    """(time, label ID) per CSV row."""
    with path.open(newline="", encoding="utf-8") as handle:
        for row in csv.reader(handle):
            try:
                yield float(row[0]), int(row[1])
            except IndexError, ValueError:
                continue


def labels(folder: Path) -> dict[int, str]:
    try:
        raw = json.loads((folder / LABELS_NAME).read_text(encoding="utf-8"))
        return {int(key): str(value) for key, value in raw.items()}
    except OSError, ValueError, AttributeError:
        return {}


def meta(folder: Path) -> dict[str, Any] | None:
    try:
        return json.loads((folder / storage.META_NAME).read_text(encoding="utf-8"))
    except OSError, ValueError:
        return None


def summary(folder: Path) -> list[dict[str, Any]]:
    result = []
    for track, path in tracks(folder).items():
        times = [time for time, _ in rows(path)]
        first, last = (times[0], times[-1]) if times else (None, None)
        result.append({"track": track, "events": len(times), "first": first, "last": last})
    return result


def project_list(root: Path) -> list[dict[str, Any]]:
    """Every project: name, whether its ZIP is built (the "done" rule), and meta.json."""
    if not root.is_dir():
        return []
    return [
        {
            "name": name,
            "done": storage.zip_path(root, name).is_file(),
            "meta": files.get(storage.META_NAME, {}).get("content"),
        }
        for name, files in storage.list_projects(root).items()
    ]


def project_events(root: Path, name: str) -> dict[str, Any]:
    """Every track's rows with the label table, for the viewer. name is already validated."""
    folder = storage.project_dir(root, name)
    return {
        "name": name,
        "meta": meta(folder),
        "labels": {str(key): value for key, value in labels(folder).items()},
        "tracks": {track: [[t, i] for t, i in rows(path)] for track, path in tracks(folder).items()},
    }
```

```python
class Clock:
    def __init__(self):
        self.now = 100.0

    def __call__(self):
        return self.now


@pytest.fixture(autouse=True)
def empty_registry():
    progress._entries.clear()
    yield
    progress._entries.clear()


def test_a_tracker_walks_its_stages():
    clock = Clock()
    tracker = progress.Tracker(PID, progress.YOUTUBE_STAGES, clock=clock)
    tracker.fraction(0.25)
    assert progress.snapshot(PID, clock=clock)["fraction"] == 0.25
    tracker.stage("rhythm")
    clock.now = 103.0
    state = progress.snapshot(PID, clock=clock)
    assert state["stage"] == "rhythm"
    assert state["done"] == 2
    assert state["total"] == 6
    assert state["fraction"] is None
    assert state["elapsed"] == 3.0
    tracker.finish()
    state = progress.snapshot(PID, clock=clock)
    assert state["finished"] is True
    assert state["done"] == 6
    assert state["error"] is None
```

```python
"""Analysis progress the SPA polls while its POST is still open (GET /progress/<id>).

In memory and per process: the image runs one gunicorn worker (app/Dockerfile), so the thread
analysing and the thread answering a poll share this registry. A second worker would only see
its own entries (docs/adr/0013). The client picks the ID; it carries no authority, only a
place to look.
"""

import re
import threading
import time
from collections.abc import Callable
from typing import Any

UPLOAD_STAGES = ("decode", "rhythm", "notes", "key", "package")
YOUTUBE_STAGES = ("download", *UPLOAD_STAGES)
KEEP_SECONDS = 600

_ID = re.compile(r"[0-9a-f]{32}")
_entries: dict[str, dict[str, Any]] = {}
_guard = threading.Lock()


def is_valid_id(value: str | None) -> bool:
    return value is not None and _ID.fullmatch(value) is not None


class Tracker:
    """One request's progress. Without a valid ID every call is a no-op, so the routes need no
    branches for clients that do not poll (curl, the MCP jobs)."""

    def __init__(
        self,
        progress_id: str | None,
        stages: tuple[str, ...],
        clock: Callable[[], float] = time.monotonic,
    ) -> None:
        self.id = progress_id if is_valid_id(progress_id) else None
        self.stages = stages
        self._clock = clock
        if self.id:
            with _guard:
                _prune(clock())
                _entries[self.id] = {
                    "stages": list(stages),
                    "stage": stages[0],
                    "done": 0,
                    "fraction": None,
                    "finished": False,
                    "error": None,
                    "started": clock(),
                    "ended": None,
                }

    def stage(self, name: str) -> None:
        if name in self.stages:
            self._update(stage=name, done=self.stages.index(name), fraction=None)

    def fraction(self, value: float) -> None:
        self._update(fraction=round(max(0.0, min(1.0, value)), 3))

    def finish(self, error: str | None = None) -> None:
        fields: dict[str, Any] = {"finished": True, "error": error, "ended": self._clock()}
        if error is None:
            fields["done"] = len(self.stages)
        self._update(**fields)

    def _update(self, **fields: Any) -> None:
        if not self.id:
            return
        with _guard:
            entry = _entries.get(self.id)
            if entry is not None:
                entry.update(fields)


def snapshot(progress_id: str, clock: Callable[[], float] = time.monotonic) -> dict | None:
    if not is_valid_id(progress_id):
        return None
    now = clock()
    with _guard:
        _prune(now)
        entry = _entries.get(progress_id)
        if entry is None:
            return None
        end = entry["ended"] if entry["ended"] is not None else now
        return {
            "stages": list(entry["stages"]),
            "stage": entry["stage"],
            "done": entry["done"],
            "total": len(entry["stages"]),
            "fraction": entry["fraction"],
            "finished": entry["finished"],
            "error": entry["error"],
            "elapsed": round(end - entry["started"], 1),
        }


def _prune(now: float) -> None:
    expired = [
        key
        for key, entry in _entries.items()
        if entry["ended"] is not None and now - entry["ended"] > KEEP_SECONDS
    ]
    for key in expired:
        del _entries[key]
```

```python
class Busy(Exception):
    """A project is being analysed; its folder must not move or vanish under the analysis."""


@contextmanager
def try_lock(*names: str) -> Iterator[None]:
    """Hold every named project's lock, or raise Busy at once. Sorted, so two renames that
    name the same pair cannot deadlock."""
    held: list[threading.Lock] = []
    try:
        for name in sorted(set(names)):
            lock = _lock(name)
            if not lock.acquire(blocking=False):
                raise Busy(name)
            held.append(lock)
        yield
    finally:
        for lock in reversed(held):
            lock.release()


def delete(root: Path, name: str) -> None:
    with try_lock(name):
        storage.delete_project(root, name)


def rename(root: Path, old: str, new: str) -> None:
    with try_lock(old, new):
        if storage.project_dir(root, new).exists() or storage.zip_path(root, new).exists():
            raise FileExistsError(new)
        storage.rename_project(root, old, new)
```

```ts
// Every URL the SPA calls lives here. Errors become ApiError with the server's own `error`
// text, so the UI shows what Flask said.

export type Meta = { name?: string; key?: string; bpm?: number } | null;
export type Project = { name: string; done: boolean; meta: Meta };
export type Config = { extensions: string[]; max_upload_mb: number };
export type Row = [number, number];
export type Events = {
  name: string;
  meta: Meta;
  labels: Record<string, string>;
  tracks: Record<string, Row[]>;
};

export class ApiError extends Error {
  constructor(
    message: string,
    readonly status: number,
  ) {
    super(message);
    this.name = "ApiError";
  }
}

function errorText(body: unknown, status: number): string {
  if (body && typeof body === "object" && "error" in body) return String(body.error);
  return `Server answered ${status}`;
}

async function get<T>(url: string): Promise<T> {
  let response: Response;
  try {
    response = await fetch(url, { headers: { Accept: "application/json" } });
  } catch {
    throw new ApiError("Server unreachable", 0);
  }
  let body: unknown = null;
  try {
    body = await response.json();
  } catch {
    body = null;
  }
  if (!response.ok) throw new ApiError(errorText(body, response.status), response.status);
  return body as T;
}

export const getConfig = () => get<Config>("/config");
export const getProjects = () => get<Project[]>("/projects");
export const getEvents = (name: string) =>
  get<Events>(`/projects/${encodeURIComponent(name)}/events`);

// XMLHttpRequest, not fetch: fetch reports no upload progress.
export function postAnalysis(
  endpoint: "/upload" | "/download_yt",
  body: FormData | string,
  onProgress: (fraction: number) => void,
): Promise<{ name: string }> {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open("POST", endpoint);
    xhr.setRequestHeader("Accept", "application/json");
    if (typeof body === "string") xhr.setRequestHeader("Content-Type", "application/json");
    xhr.upload.onprogress = (event) => {
      if (event.lengthComputable) onProgress(event.loaded / event.total);
    };
    xhr.upload.onload = () => onProgress(1);
    xhr.onerror = () => reject(new ApiError("Server unreachable", 0));
    xhr.onload = () => {
      let parsed: unknown = null;
      try {
        parsed = JSON.parse(xhr.responseText);
      } catch {
        parsed = null;
      }
      if (xhr.status === 200 && parsed && typeof parsed === "object" && "name" in parsed) {
        resolve({ name: String(parsed.name) });
      } else {
        reject(new ApiError(errorText(parsed, xhr.status), xhr.status));
      }
    };
    xhr.send(body);
  });
}
```

```ts
import { useCallback, useEffect, useState } from "react";

type State<T> = { data: T | null; error: unknown; loading: boolean };

// load must be stable (a module function or useCallback): it is the effect's dependency.
export function useLoad<T>(load: () => Promise<T>) {
  const [state, setState] = useState<State<T>>({ data: null, error: null, loading: true });
  const [tick, setTick] = useState(0);

  useEffect(() => {
    let live = true;
    load().then(
      (data) => live && setState({ data, error: null, loading: false }),
      (error: unknown) => live && setState({ data: null, error, loading: false }),
    );
    return () => {
      live = false;
    };
  }, [load, tick]);

  const reload = useCallback(() => {
    setState((current) => ({ ...current, loading: true }));
    setTick((value) => value + 1);
  }, []);

  return { ...state, reload };
}

export function message(error: unknown): string | null {
  if (error == null) return null;
  return error instanceof Error ? error.message : String(error);
}
```

```ts
import type { Row } from "./api";

// The analysis's track names (app/events.py TRACK_ORDER), drums first, pitched last.
export const TRACK_ORDER = ["kick", "snare", "hh", "beats", "bass", "chords", "melody"];
export const SHORT: Record<string, string> = {
  kick: "KI",
  snare: "SN",
  hh: "HH",
  beats: "BT",
  bass: "BA",
  chords: "CH",
  melody: "ME",
};
export const MIN_SPAN = 2;
// Label IDs below this are MIDI pitches; 128 and up are drum and beat labels (analysis.LABELS).
export const PITCH_LIMIT = 128;

export function laneOrder(tracks: Record<string, Row[]>): string[] {
  const names = Object.keys(tracks);
  const known = TRACK_ORDER.filter((name) => names.includes(name));
  return [...known, ...names.filter((name) => !TRACK_ORDER.includes(name)).sort()];
}

export function durationOf(tracks: Record<string, Row[]>): number {
  let last = 0;
  for (const rows of Object.values(tracks)) for (const [time] of rows) last = Math.max(last, time);
  return Math.max(last, MIN_SPAN);
}

export function clampZoom(pps: number, duration: number, width: number): number {
  if (width <= 0) return pps;
  const fit = width / Math.max(duration, MIN_SPAN);
  const closest = width / MIN_SPAN;
  return Math.min(Math.max(pps, fit), Math.max(fit, closest));
}

const STEPS = [0.5, 1, 2, 5, 10, 15, 30, 60, 120, 300, 600, 1200];

export function rulerStep(pps: number): number {
  return STEPS.find((step) => step * pps >= 64) ?? STEPS[STEPS.length - 1];
}

export function pitchRange(rows: Row[]): [number, number] | null {
  const pitches = rows.map(([, id]) => id).filter((id) => id < PITCH_LIMIT);
  if (pitches.length === 0) return null;
  return [Math.min(...pitches), Math.max(...pitches)];
}

export function pitchToY(pitch: number, range: [number, number] | null, height: number): number {
  if (!range || range[1] === range[0]) return height / 2;
  const [low, high] = range;
  return height - 2 - ((pitch - low) / (high - low)) * (height - 4);
}

export function visibleRows(rows: Row[], from: number, to: number): Row[] {
  return rows.filter(([time]) => time >= from && time <= to);
}

export function laneStats(rows: Row[]) {
  if (rows.length === 0) return { count: 0, first: null, last: null };
  const times = rows.map(([time]) => time);
  return { count: rows.length, first: Math.min(...times), last: Math.max(...times) };
}

export function formatTime(seconds: number): string {
  const minutes = Math.floor(seconds / 60);
  return `${minutes}:${(seconds - minutes * 60).toFixed(1).padStart(4, "0")}`;
}
```

```tsx
export default function Timeline({ events }: { events: Events }) {
  const lanes = laneOrder(events.tracks);
  const duration = durationOf(events.tracks);
  const scroller = useRef<HTMLDivElement>(null);
  const canvas = useRef<HTMLCanvasElement>(null);
  const [width, setWidth] = useState(0);
  const [left, setLeft] = useState(0);
  const [zoom, setZoom] = useState(0);
  const [picked, setPicked] = useState<string | null>(null);
  const spacer = useRef<HTMLDivElement>(null);
  const pendingLeft = useRef<number | null>(null);
  const pps = clampZoom(zoom || (width ? width / duration : 1), duration, width);
  const view = useRef({ pps, left, width });

  function zoomAt(factor: number, anchor: number) {
    const { pps: current, left: from, width: visible } = view.current;
    const next = clampZoom(current * factor, duration, visible);
    const time = (from + anchor) / current;
    pendingLeft.current = Math.max(0, time * next - anchor);
    setZoom(next);
  }
  const zoomRef = useRef(zoomAt);

  // Refs are written after render, never during it (react-hooks rule); the native listeners
  // read them when an event arrives.
  useLayoutEffect(() => {
    view.current = { pps, left, width };
    zoomRef.current = zoomAt;
  });

  // The spacer's width goes through the DOM: the CSP refuses style="" in HTML, not this.
  useEffect(() => {
    if (spacer.current) spacer.current.style.width = `${duration * pps}px`;
  }, [duration, pps]);

  useEffect(() => {
    const element = scroller.current;
    if (!element) return;
    const measure = () => setWidth(element.clientWidth);
    measure();
    if (typeof ResizeObserver === "undefined") return;
    const observer = new ResizeObserver(measure);
    observer.observe(element);
    return () => observer.disconnect();
  }, []);

  // Native listeners: React's wheel and touch listeners are passive, and only an active
  // listener can stop ctrl+wheel and pinch from zooming the whole page.
  useEffect(() => {
    const element = scroller.current;
    if (!element) return;
    let pinch = 0;
    const onWheel = (event: WheelEvent) => {
      if (!event.ctrlKey) return;
      event.preventDefault();
      const anchor = event.clientX - element.getBoundingClientRect().left;
      zoomRef.current(event.deltaY < 0 ? 1.25 : 0.8, anchor);
    };
    const distance = (touches: TouchList) =>
      Math.hypot(touches[0].clientX - touches[1].clientX, touches[0].clientY - touches[1].clientY);
    const onTouchMove = (event: TouchEvent) => {
      if (event.touches.length !== 2) return;
      event.preventDefault();
      const now = distance(event.touches);
      if (pinch) {
        const middle = (event.touches[0].clientX + event.touches[1].clientX) / 2;
        zoomRef.current(now / pinch, middle - element.getBoundingClientRect().left);
      }
      pinch = now;
    };
    const onTouchEnd = () => {
      pinch = 0;
    };
    element.addEventListener("wheel", onWheel, { passive: false });
    element.addEventListener("touchmove", onTouchMove, { passive: false });
    element.addEventListener("touchend", onTouchEnd);
    return () => {
      element.removeEventListener("wheel", onWheel);
      element.removeEventListener("touchmove", onTouchMove);
      element.removeEventListener("touchend", onTouchEnd);
    };
  }, []);

  useEffect(() => {
    if (pendingLeft.current !== null && scroller.current) {
      scroller.current.scrollLeft = pendingLeft.current;
      pendingLeft.current = null;
    }
  }, [pps]);

  useEffect(() => {
    const element = canvas.current;
    const context = element?.getContext?.("2d");
    if (!element || !context || width === 0) return;
    const lane = laneHeight();
    const height = RULER_H + lanes.length * lane;
    const ratio = window.devicePixelRatio || 1;
    element.width = Math.round(width * ratio);
    element.height = Math.round(height * ratio);
    element.style.width = `${width}px`;
    element.style.height = `${height}px`;
    context.setTransform(ratio, 0, 0, ratio, 0, 0);
    const css = getComputedStyle(element);
    const colour = (name: string) => css.getPropertyValue(name).trim() || "#ece9f7";
    context.clearRect(0, 0, width, height);

    const from = left / pps;
    const to = (left + width) / pps;
    const step = rulerStep(pps);
    context.fillStyle = colour("--muted");
    context.font = "11px sans-serif";
    for (let time = Math.ceil(from / step) * step; time <= to; time += step) {
      const x = time * pps - left;
      context.fillRect(x, RULER_H - 6, 1, 6);
      context.fillText(formatTime(time).replace(/\.0$/, ""), x + 3, 11);
    }

    lanes.forEach((track, index) => {
      const top = RULER_H + index * lane;
      context.fillStyle = colour("--line");
      context.fillRect(0, top, width, 1);
      const rows = events.tracks[track];
      const range = pitchRange(rows);
      context.fillStyle = colour(COLOURS[track] ?? "--ink");
      for (const [time, id] of visibleRows(rows, from, to)) {
        const x = time * pps - left;
        if (range && id < 128) {
          context.fillRect(x, top + pitchToY(id, range, lane) - 2, 3, 4);
        } else {
          context.fillRect(x, top + 4, 2, lane - 8);
        }
      }
    });
  }, [events, lanes, pps, left, width]);

  const stats = picked ? laneStats(events.tracks[picked] ?? []) : null;
  return (
    <section className="card timeline">
      <div className="zoom">
        <button type="button" aria-label="Zoom out" onClick={() => zoomAt(0.8, width / 2)}>
          −
        </button>
        <button type="button" aria-label="Zoom in" onClick={() => zoomAt(1.25, width / 2)}>
          +
        </button>
        <span className="muted num">{formatTime(duration)}</span>
      </div>
      <div className="lanes">
        <div className="labels">
          {lanes.map((track) => {
            const count = events.tracks[track].length;
            return (
              <button
                key={track}
                type="button"
                data-track={track}
                className={picked === track ? "lane on" : "lane"}
                aria-label={`${track}, ${count} events`}
                onClick={() => setPicked(picked === track ? null : track)}
              >
                <span className="long">{track}</span>
                <span className="short">{SHORT[track] ?? track.slice(0, 2).toUpperCase()}</span>
              </button>
            );
          })}
        </div>
        <div
          ref={scroller}
          className="scroller"
          data-testid="timeline-scroller"
          onScroll={(event) => setLeft(event.currentTarget.scrollLeft)}
        >
          <div className="spacer" ref={spacer}>
            <canvas
              ref={canvas}
              role="img"
              aria-label={`Timeline of ${lanes.length} tracks, ${formatTime(duration)} long`}
            />
          </div>
        </div>
      </div>
      {picked && stats && (
        <p className="muted num">
          {picked}: {stats.count} events
          {stats.first !== null && stats.last !== null
            ? `, ${formatTime(stats.first)} to ${formatTime(stats.last)}`
            : ""}
        </p>
      )}
    </section>
  );
}
```

```ts
async function request<T>(url: string, init: RequestInit = {}): Promise<T> {
  const headers: Record<string, string> = { Accept: "application/json" };
  if (typeof init.body === "string") headers["Content-Type"] = "application/json";
  let response: Response;
  try {
    response = await fetch(url, { ...init, headers });
  } catch {
    throw new ApiError("Server unreachable", 0);
  }
  if (response.status === 204) return undefined as T;
  let body: unknown = null;
  try {
    body = await response.json();
  } catch {
    body = null;
  }
  if (!response.ok) throw new ApiError(errorText(body, response.status), response.status);
  return body as T;
}

const get = <T>(url: string) => request<T>(url);

export const deleteProject = (name: string) =>
  request<void>(`/projects/${encodeURIComponent(name)}`, { method: "DELETE" });
export const renameProject = (name: string, to: string) =>
  request<{ name: string }>(`/projects/${encodeURIComponent(name)}/rename`, {
    method: "POST",
    body: JSON.stringify({ to }),
  });
```

```python
def fetch(url: str) -> tuple[int, bytes]:
    try:
        with urllib.request.urlopen(url, timeout=30) as response:
            return response.status, response.read()
    except urllib.error.HTTPError as exc:
        return exc.code, exc.read()


def check_spa(base: str, get=fetch) -> list[str]:
    """The built SPA: / serves index.html, and the first script it references loads."""
    status, body = get(f"{base}/")
    if status != 200 or b'<div id="root">' not in body:
        return [f"/ answered {status}, expected the SPA"]
    match = re.search(rb'src="(/assets/[^"]+\.js)"', body)
    if not match:
        return ["index.html references no /assets/*.js"]
    asset = match.group(1).decode()
    status, _ = get(f"{base}{asset}")
    return [] if status == 200 else [f"{asset} answered {status}"]
```

- [ ] **Step 1: ADR 0013**

```markdown
# 0013. React SPA served by Flask from a Node build stage

- **Status:** Accepted
- **Date:** 2026-10-27

## Context

The page was one Jinja template with Bootstrap from a CDN and a script that fetched a ZIP.
The new UI needs a track viewer and the saber-tooth look, which a component framework and a
build step serve better. The service runs as one container behind a same-origin POST check
and a strict CSP.

## Decision

The SPA lives in `web/` (React, Vite, TypeScript, plain CSS). A Node stage in `app/Dockerfile`
builds it; Flask serves `index.html` for its routes and the hashed assets under `/assets/`.
Node never runs at runtime. The CDN is gone, so the CSP allows `'self'` only.

## Consequences

**Gain.** One origin, so the same-origin check and the CSP stay simple. One container and one
port (8002).

**Cost.** The image build needs Node and npm; a checkout without Node serves a 503 at `/`
until `task web:build`, while the API keeps working.

**Constraint.** Analysis progress (`app/progress.py`) lives in the process's memory, and the
SPA polls it from another request. That holds because the image runs one gunicorn worker
(several threads). A second worker would answer some polls without the entry; moving to
several workers means moving the registry out of process first.

## Alternatives considered

**An nginx container serving `dist/`.** Splits static files from the API, but adds a service,
a proxy configuration and a second origin to secure.
```
